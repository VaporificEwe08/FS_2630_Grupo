## [1.0.0-Beta] - 2026-08-05 (Ejemplo de Entrega Parcial)

### 🚀 Añadido (Added)
*   **Autenticación de usuarios:** Creado el sistema de login y registro conectado a la base de datos.
*   **Vistas principales:** Maquetación del tablero Kanban y el perfil de usuario.

### 🛠️ Modificado (Changed)
*   **Estructura del proyecto:** Refactorización de carpetas para cumplir con la arquitectura MVC.
*   **Estilos:** Actualización de la paleta de colores global según requerimientos de diseño.

### 🐛 Corregido (Fixed)
*   **Error de CORS:** Solucionado el problema de comunicación entre el frontend y el backend locales.
*   **Validación de formularios:** Corregido el bug que permitía contraseñas vacías en el registro.

### 🗑️ Eliminado (Removed)
*   **Vistas de prueba:** Se eliminaron las plantillas HTML temporales utilizadas en la fase de mockup.
